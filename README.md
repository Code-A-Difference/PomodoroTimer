# Pomodoro Timer

A focus timer that alternates work sessions with short breaks, offering a longer break after every four completed focus sessions. Session lengths are adjustable, and the timer can be paused, resumed, reset or skipped.

An optional task field helps you choose one thing to focus on. The tool tracks completed sessions, plays two groups of three clear beeps when a focus or break session ends, with a Test beep control, and saves your task, settings and timer progress in the browser. Each new session starts when you choose.
